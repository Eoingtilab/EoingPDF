# 어잉PDF 2.2.2

## 배포 기준

- 최신 버전: `2.2.2`
- 설치형: `EoingPDF-2.2.2-Setup-x64.exe`
- 단일 실행 포터블: `EoingPDF-2.2.2-portable.exe`
- 업데이트 배포 저장소: `Eoingtilab/nalapps-releases`
- 업데이트 매니페스트: `products/eoingpdf/latest.json`
- 배포 태그: `utility-eoingpdf-v2.2.2`
- EDD 상품 26818: 라이선스 활성화/사용 권한 확인 전용

## 2.2.2 변경 사항

- 자동 업데이트의 버전·다운로드 URL·SHA-256 기준을 EDD 상품 메타데이터에서 NallaApps 통합 릴리스 저장소로 분리했습니다.
- 설치형과 단일 실행 포터블 모두 GitHub Release 자산을 직접 사용합니다.
- 다운로드 전후 SHA-256 검증과 허용된 GitHub 릴리스 경로 검증을 수행합니다.
- PDF 페이지 순서 변경, 썸네일/목록 전환, `더 많은 기능` 메뉴, 저장 버튼 배치를 개선했습니다.
- HWP/HWPX 변환 종료 시 원본 문서 저장 확인창이 나타나는 문제를 보완했습니다.

app.nal.la의 상품 페이지에 표시되는 버전 표시는 별도 콘텐츠이므로, 배포 시 동일 버전으로 맞춰야 합니다.
