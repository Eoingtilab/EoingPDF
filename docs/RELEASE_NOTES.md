# 이전 릴리스 · 어잉PDF 2.3.0

배포일: 2026-10-13 · Windows 10/11 x64

## 현재 PDF에서 직인·서명 배치

PDF 상단 `더 많은 기능` 왼쪽의 **직인 및 서명 넣기**로 JPG·PNG를 선택합니다. 흰 배경을 자동 제거하고 현재 보이는 영역에 배치합니다. 직인을 끌어 이동하거나 오른쪽 아래 모서리와 너비 입력으로 크기를 맞춘 뒤 마지막에 **저장**을 누릅니다.

여러 직인을 배치할 수 있으며, 긴 페이지에서는 드래그 중 자동 스크롤합니다. 저장 결과는 같은 뷰어에 표시합니다. 원본 파일과 기존 출력 파일은 덮어쓰지 않습니다.

## 저장 전 미리보기

뷰어의 `더 많은 기능`에서 PDF 결과 도구에 **미리보기 적용**을 추가했습니다. 양식 입력도 현재 PDF에 먼저 적용합니다. 결과를 확인하고 편집을 이어간 뒤 새 PDF로 저장합니다. ZIP·Markdown 등의 내보내기는 별도 파일로 저장합니다.

페이지 변경·직인·미리보기는 슬라이드쇼에서도 보이며, 판서 저장 결과를 같은 PDF 뷰어에 표시합니다. 페이지 이동·삭제·저장 시 양식 필드 구조를 잃는 문제를 수정했고, 실제 필드값과 위젯값·암호 유지를 검사했습니다.

## 슬라이드쇼 판서 도구

- 부분 지우개와 선택·이동·크기 조절
- 실행 취소·다시 실행, 선택 삭제·현재 화면 지우기
- 펜·형광펜·임시 펜·텍스트와 직선·사각형·타원·화살표
- 색·굵기·글자 크기와 도형 채우기
- 이미지 파일 넣기, 클립보드 이미지 붙여넣기, 앱에서 직접 영역을 선택하는 화면 캡처
- 이미지와 판서를 PDF로 저장하며 기존 텍스트를 유지

단축키: `E` 지우개, `P` 펜, `H` 형광펜, `T` 텍스트, `Ctrl+Z` 실행 취소, `Ctrl+Y` 다시 실행, `Ctrl+V` 이미지 붙여넣기, `Delete` 선택 삭제.

지우개는 추가한 판서를 지우며 원본 PDF 내용이나 이미지 픽셀을 지우지 않습니다. 이미지는 선택 삭제로 제거합니다. 픽셀 편집·자르기·회전·영역 채우기는 이번 범위에 포함하지 않습니다.

## 배포와 검증

설치형: `EoingPDF-2.3.0-Setup-x64.exe` · 포터블: `EoingPDF-2.3.0-portable.exe`

공식 배포: `Eoingtilab/nalapps-releases`, 태그 `utility-eoingpdf-v2.3.0`. 앱은 공식 URL과 SHA-256을 확인합니다. 기존 라이선스 방식을 유지하고 이전 안정 버전 2.2.3을 보존합니다.

신규 편집·회전 좌표·양식 구조·원본 보존·Windows GPU 지우개/실행 취소를 검사했습니다. 배포 빌드에서 전체 자동 검사·Windows 화면 검사·실행파일 기능·다국어·업데이트 복원 검사를 수행합니다. 실행파일 상태 검사에는 JPG 디코더와 직인·판서 편집 모듈도 포함합니다.

물리 펜·프린터·다중 모니터 장비와 사용자별 원본 문서는 별도 인수 시험을 수행하지 않았습니다. 화면 캡처 좌표·취소·복귀는 시험 화면으로 검사했고, 실제 사용자 데스크톱은 자동 시험에서 캡처하지 않았습니다.

## 이전 릴리스 기록 (2.2.3)

# 어잉PDF 2.2.3

배포일: 2026-10-09 · Windows 10/11 x64 · 안정화 업데이트

## 주요 수정

- Word 등에서 만든 PDF 표의 빈 셀을 입력 가능한 양식으로 만들 때 칸을 놓치는 문제를 수정했습니다.
- 공유 테두리·병합 셀·네 개의 선으로 그린 박스와 얇은 채움 도형으로 저장된 표 테두리·밑줄을 감지합니다.
- 행 구분선을 행 전체 입력 칸으로 잘못 잡는 문제를 보완했습니다.
- 높은 텍스트 칸은 여러 줄 입력을 지원합니다.
- 처리 라이브러리의 안내 출력이 저장 작업을 중단시키지 않도록 보완했습니다.

## 사용 방법

1. PDF에서 **더 많은 기능 → 입력 가능한 양식 만들기**를 선택합니다.
2. 감지 결과 검토 화면에서 위치와 종류를 확인하고 잘못 잡힌 칸은 제외합니다.
3. 새 PDF로 저장한 뒤 뷰어 하단 **양식 입력**에서 값을 입력합니다.
4. 입력 내용을 새 PDF로 저장하고 결과를 확인합니다.

원본과 기존 출력 파일은 덮어쓰지 않습니다. 스캔·촬영 이미지와 테두리 없는 표는 자동 감지 대상이 아닙니다. 모든 서식의 감지율과 외부 뷰어별 한글 재편집 호환성을 보장하지 않으므로 생성 결과를 확인해 주세요.

## 배포 파일 및 업데이트

- 설치형: `EoingPDF-2.2.3-Setup-x64.exe`
- 단일 실행 포터블: `EoingPDF-2.2.3-portable.exe`
- 공식 배포: `Eoingtilab/nalapps-releases`, 태그 `utility-eoingpdf-v2.2.3`
- 업데이트 정보: `products/eoingpdf/latest.json`
- 원본 소스: `Eoingtilab/EoingPDF`

앱은 공식 다운로드 URL과 SHA-256을 검증합니다. 기존 라이선스와 업데이트 방식을 유지하며, 이 업데이트는 Microsoft Store 패키지 제출을 포함하지 않습니다.

## 검증 및 복원

실제 Word 출력 PDF의 빈 셀 생성·한글 입력·다시 열기를 확인했습니다. 정식 소스의 전체 자동 검사 579개가 건너뜀 없이 통과했고 Windows UI 검사도 통과했습니다. 설치형에 포함될 실행파일과 단일 포터블의 자동 양식 생성·한글 저장·업데이트 복원 검사를 배포 빌드의 필수 검사로 수행합니다.

이전 정식 2.2.2의 배포 파일은 보존합니다. 문제가 있으면 2.2.2를 다시 설치하거나 앱의 검증된 업데이트 백업 복원 기능을 사용하세요. 사용자 PDF를 직접 수정하거나 삭제하지 않습니다.
