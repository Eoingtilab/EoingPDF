# 어잉PDF 2.0.1

Windows 다크 테마에서도 페이지 번호와 확대 비율을 읽기 쉽게 표시하는 수정이 포함되어 있습니다.

탐색기에서 파일을 선택하고 우클릭으로 PDF 변환·병합·핵심문장 요약을 실행합니다.
PDF 뷰어와 중간 페이지 삭제를 포함하며, 원본은 보존하고 결과를 새 파일로 저장합니다.

- Pretendard UI, 페이지 이동·확대·너비 맞춤
- PDF/이미지/텍스트 혼합 처리와 실제 Office·한컴 변환
- Windows 내장 OCR을 이용한 스캔 문서 텍스트 추출
- 페이지 출처를 표시하는 오프라인 발췌 요약
- 취소, 출력 이름 충돌 방지, 부분 실패 표시

## 설치

포터블 ZIP을 원하는 폴더에 풀고 `install-context-menu.cmd`를 실행합니다.
열리는 Windows 기본 앱 설정에서 `.pdf`에 어잉PDF를 선택하면 PDF 더블클릭으로 뷰어가 열립니다.
Windows 11의 우클릭 기능은 **더 많은 옵션 표시**에서 사용할 수 있습니다.

Office 및 HWP/HWPX 변환에는 해당 Microsoft Office/한컴 한글 설치가 필요합니다.
요약은 생성형 AI가 아닌 원문 핵심문장 발췌입니다. OCR에는 Windows의 해당 언어 인식 기능이 필요합니다.

Windows 11과 현재 PC의 Office/한컴 한글 2022에서 검증했습니다. 자세한 내용은 `docs/VALIDATION.md`를 참고하세요.
소스 ZIP과 SHA256 체크섬을 함께 제공합니다. 저장소와 배포는 비공개입니다.
