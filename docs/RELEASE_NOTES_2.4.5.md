# 어잉PDF 2.4.5

뷰어의 상단에서 슬라이드쇼와 직인·서명을 바로 실행하고, 편집 도구와 페이지 목록은 필요한 때 펼치거나 접을 수 있습니다. 문서 위에서 Ctrl 키를 누른 채 마우스 휠을 움직이거나 하단 확대·축소 버튼을 사용해 배율을 바꿀 수 있습니다. 휠만 사용하면 기존처럼 문서와 페이지를 이동합니다.

밝은 테마와 어두운 테마 및 한국어·영어·일본어를 지원합니다. 기존 PDF 원본과 라이선스 데이터는 그대로 유지하며, 편집한 문서는 사본으로 저장합니다.

설치형과 포터블의 배포 정보 및 검증 기록은 [공개 배포 기록](https://github.com/Eoingtilab/nalapps-releases/blob/main/products/eoingpdf/2.4.5/validation.json)을 확인하세요.
