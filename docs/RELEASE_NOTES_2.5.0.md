# 어잉PDF 2.5.0

- **통합 PDF 워크벤치 UI**: 왼쪽 활동 레일과 문서 라이브러리(여러 파일 관리·일괄 병합·일괄 PDF 변환), 중앙 PDF 뷰어/멀티툴/빈 홈 전환, 오른쪽 인라인 도구 검색(`Ctrl+K`) 및 자동화 파이프라인(`PDF Processor`)을 한 화면에 통합했습니다.
- **슬라이드쇼 · 직인/서명 강조**: 상단 도구막대에 **슬라이드쇼 · F5**와 **직인·서명 넣기**를 눈에 띄는 테두리 강조와 함께 최전면에 배치했으며, 마우스 직접 그리기·글자 도장 생성(`SignDrawDialog`)을 추가했습니다.
- **화면 떨림 버그 수정**: 특정 종횡비 PDF(`595x820`, `500x700` 등)를 `너비 맞춤`으로 열 때 스크롤바 폭 변화로 확대 배율이 왕복 진동하던 문제를 해결했습니다.
- **다른 이름으로 저장 · 형식 변환 (`Ctrl+Shift+S`)**: PDF, PDF/A, PNG/JPG(묶음/1장/세로 긴 이미지), TXT, Markdown, HTML, JSON, XML, SVG(ZIP), DXF(ZIP) 등 13개 저장 형식을 손쉽게 선택해 원본 보존 상태로 새 파일에 저장합니다.
- **53+ PDF 도구 및 자동화 파이프라인**: 회전, 자동 방향 교정, 페이지 번호, 표준 규격 맞춤, 빈 페이지 삽입, PDF 겹쳐 넣기, 용량 분할, 원본 이미지 ZIP 추출, HTML↔PDF, JSON/XML/PDF/A 변환, 세부 권한 설정, 양식 잠금 해제, 첨부 파일 관리, 목차/책갈피 편집, 오프라인 QR 코드 스탬프, 활성 스크립트·JS 소독, 텍스트·시각 비교 4모드, PDF 상세 규격 검사 및 순차 파이프라인 프리셋을 지원합니다.
