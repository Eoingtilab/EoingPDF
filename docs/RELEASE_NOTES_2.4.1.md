# 어잉PDF 2.4.1

배포일: 2026-10-14 · Windows 10/11 x64

PDF 뷰어 하단의 페이지 이동 화살표가 시각적 방향과 반대로 움직이던 문제를 수정했습니다.

- 위 ▲: 이전 페이지로 이동합니다(16 → 15).
- 아래 ▼: 다음 페이지로 이동합니다(16 → 17).
- 안내 문구와 PgUp/PgDown 이동 방향도 일치합니다. 첫·마지막 페이지를 벗어나지 않습니다.

2.4.0의 작업별 도구 검색, 직인 배치, 실행 취소·다시 실행과 변경 내역 기능을 포함합니다.

세 언어에서 실제 23페이지 시험 PDF로 화살표·키보드·페이지 범위와 원본 바이트 보존을 검사합니다. 전체 자동 검사, Windows 화면 검사, 설치형·포터블 실행파일과 공개 업데이트 다운로드 검증을 수행합니다. 사용자별 원본 PDF와 실제 기존 설치 교체는 이번 검사에 포함하지 않습니다.
