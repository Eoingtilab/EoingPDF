# [MASTER SPEC v2.0] EoingPDF: 우주 최강 PDF 유틸리티 통합 개발 명세서
- 저장소: https://github.com/Eoingtilab/EoingPDF
- 디자인 시스템: `Eoingtilab/nalapps-windows-sdk`
- 핵심 철학: Zero-Bloat (상주 데몬 0MB), 100% 로컬 오프라인(Air-Gapped), 윈도우 네이티브 셸 통합

## 0. 아키텍처 및 디자인 시스템 기반 (`nalapps-windows-sdk`)
1. **디자인 통일:** 모든 모달, 플로팅 칩, 발표 HUD, 프리뷰어는 `nalapps-windows-sdk`의 Fluent 디자인(Mica/Acrylic 머티리얼, 라이트/다크 테마 동기화, 시스템 폰트 규격) 준수.
2. **다국어(i18n):** 하드코딩 문자열 배제. `locales/{ko-KR, en-US, ja-JP}.json` 리소스 분리 및 OS 로케일 자동 동기화 (우클릭 레지스트리 메뉴 명칭 포함).
3. **Zero-Bloat 비상주 원칙:** 백그라운드 상주 프로세스 절대 금지. 이벤트 트리거 시에만 구동 후 메모리 반납.
4. **포터블 단일 바이너리:** 단일 실행 파일(`.exe`) 지원 및 앱 내부 `[우클릭 셸 메뉴 등록 / 해제]` 스위치 제공.

## 1. 30ms 마이크로 스니핑 & 선제 진단 엔진 (Proactive Diagnostics)
파일 선택(QuickLook) 또는 우클릭 시, 30ms 이내에 헤더와 첫 페이지만 비동기 분석하여 최적의 액션을 플로팅 칩으로 먼저 제안.

- **[D-01] 신분증/증빙서류 감지:** 비표준 규격(A4 미만) + 모서리 기울어짐 + "주민등록/면허/통장" 텍스트 감지 시
  → `[🛡️ 원클릭 안심 제출]` 제안 (자동 수평 보정 + 그림자 제거 + 고유식별번호 자동 마스킹 일괄 실행).
- **[D-02] 텍스트 먹통 스캔본 감지:** 폰트 스트림 0개 또는 ToUnicode 매핑 유실 감지 시
  → `[🔍 검색/복사 가능한 PDF로 1초 변환]` 제안 (Windows 내장 로컬 OCR 투명 텍스트 레이어 합성).
- **[D-03] 외부 유출 위험 감지:** 작성자 PC명, 수정 이력, 비가시 코멘트, XMP 메타데이터 존재 시
  → `[⚠️ 유출 위험 메타데이터 소독 후 사본 생성]` 제안.
- **[D-04] 발표 슬라이드 감지:** 16:9 또는 4:3 가로 비율 + 10페이지 이상 감지 시
  → `[🖥️ 발표자 모드(HUD) 시작]` 또는 `[🖨️ 4-Up/소책자 용지 절약 인쇄]` 제안.
- **[D-05] 다크 테마 슬라이드 감지:** 배경 70% 이상이 어두운 문서의 인쇄 트리거 시
  → `[💡 토너 90% 절약 배경 반전본 생성]` 제안 (사진/로고 컬러는 보존하고 배경만 백색화).
- **[D-06] 계약서/견적서 양식 감지:** "견적서/계약서/합의서" 키워드 + 직인/서명 감지 시
  → `[🔒 텍스트/도장 위변조 방지 플래트닝]` 제안 (300DPI 단일 이미지 레이어로 박제).
- **[D-07] 표(Table) 밀집 문서 감지:** 벡터 격자선 및 숫자 비율 40% 이상 감지 시
  → `[📊 Excel / Markdown 표 구조로 즉시 복사]` 제안.
- **[D-08] 연속 캡처 감지:** 윈도우 캡처(`Win+Shift+S`) 연속 2회 이상 발생 시
  → `[📋 캡처한 이미지들을 단일 PDF 보고서로 묶기]` 제안.
- **[D-09] 지능형 파일명 자동 추천:** 문서 첫머리 핵심 텍스트를 파싱하여 `[제출용] 사업계획서_소독됨.pdf` 형태로 자동 명명.
- **[D-10] 비파괴 비교 슬라이더:** 보정/마스킹 전, 원본과 보정본을 좌우로 밀어서 대조하는 Before & After 미니 슬라이더 제공.

## 2. 프레젠테이션 HUD & 초경량 실시간 판서 오버레이

### 2.1 발표자 듀얼스크린 모드 (Presenter HUD)
- `F5` / `Shift + F5` 실행 시 프로젝터(청중 화면)에는 4K 전체화면, 노트북에는 발표자 전용 HUD 출력.
- **HUD 인터페이스:** 현재 슬라이드, 다음 슬라이드 미리보기, 경과 시간 타이머, 페이스메이커(시간 지연 시 노랑/빨강 시각 경고).
- **대본 자동 연동:** 원본 PDF 내부의 주석(Annotation) 및 스티커 메모를 발표 대본으로 자동 파싱하여 HUD 우측에 대형 폰트로 출력.
- **제어 단축키:** `B`(블랙아웃 암전), `W`(화이트아웃), `G`(전 페이지 바둑판 썸네일 그리드 점프 네비게이터), `S`(마우스 주변 스포트라이트), `Ctrl+L`(디지털 레이저 포인터), `Space`(커튼식 단계별 단락 노출).

### 2.2 초경량 실시간 판서 오버레이 (Live Stage Overlay)
- `WS_EX_TRANSPARENT` Direct2D 무테 투명 캔버스를 화면 최상단에 120fps로 오버레이 (평상시 클릭 관통, 판서 모드 시 이벤트 포착).
- **스마트 제스처 도형 스냅:** 거칠게 그린 원, 사각형, 화살표, 별표(★), 체크(V)를 반듯한 벡터 도형/스탬프로 0.1초 만에 자동 보정.
- **자석 흡착 형광펜:** 텍스트 라인의 바운딩 박스($y$축)에 자석처럼 달라붙어 자를 댄 듯 반듯하게 칠해지는 하이라이트.
- **플로팅 라이브 타이핑:** 여백 더블클릭 시 즉시 반투명 텍스트 박스 생성 (배경 명암 자동 감지 글자색 반전).
- **휘발성 고스트 잉크:** 판서 후 3초 뒤 스스로 페이드아웃되어 지워지는 임시 강조 펜.
- **즉석 칠판/화이트보드:** `B` 키(블랙보드), `W` 키(화이트보드)로 슬라이드 위에 즉시 전체 판서 공간 소환.
- **혜성 레이저 트레일:** 마우스 이동 시 0.5초간 빛나는 궤적이 남는 고시인성 레이저 포인터.
- **판서본 분기 저장 (Bake or Discard):** 강의 종료 시 필기 데이터를 디스플레이 DPI 및 `Page.derotation_matrix`와 역산하여 표준 72 DPI PDF 벡터 주석으로 오차 없이 합성한 `[강의록]파일명_판서본.pdf` 생성 지원.

## 3. 포렌식, 프라이버시 및 보안 극대화

- **[S-01] 문맥 인식 민감정보 영구 파기 (Auto-Redaction):**
  - 단순 오버레이가 아닌 PDF 텍스트 스트림 자체를 물리적 삭제 (`page.add_redact_annot()` + `page.apply_redactions()`).
  - 주민등록번호(`\d{6}-[1-4]\d{6}`), 전화번호, 이메일, 신용카드 번호(Luhn 체크), 미국 SSN(3-2-4자리) 정규식 자동 탐색.
- **[S-02] 안티 포렌식 추적 흔적 박멸 (Ghost Buster):**
  - 프린터 하드웨어 추적용 노란 미세 점(MIC) 패턴 중화.
  - 비표시 제로 너비 공백(Zero-Width Space) 및 마이크로 투명 텍스트 레이어 완전 박멸.
- **[S-03] 메타데이터 심층 소독:** Author, Creator, Producer, ModDate, 사내 파일 경로, XMP 패킷 영구 초기화.
- **[S-04] 계약서 위변조 방지 플래트닝:** 텍스트 수정 및 직인 도용 방지를 위해 전 페이지를 300DPI 무손실 단일 이미지로 래스터라이징 병합.
- **[S-05] AES-256 암호화 및 권한 제어:** User PW(열람) / Owner PW(인쇄·복사·편집 방지 권한 플래그) 분리 설정 및 해제 다이얼로그.
- **[S-06] 워터마크 엔진:** 대각선 45도 텍스트(대외비, 사본 등) 및 투명 PNG 로고/직인 워터마크 합성.

## 4. 문서 지능 및 차세대 인터랙션

- **[I-01] 종이 서식 전자양식화 (Auto AcroForm):**
  - 인쇄용 PDF의 밑줄(`_____`), 빈 박스(`[  ]`), 체크 칸을 감지하여 실제 타이핑 가능한 인터랙티브 폼 필드(AcroForm TextField & Checkbox)로 자동 변환.
- **[I-02] 폐쇄망 다중 문서 시맨틱 검색 (Air-Gapped Multi-PDF RAG):**
  - 로컬 양자화 경량 임베딩 모델(ONNX) 탑재 (RAM 100MB 이하 소모).
  - 인터넷 차단 환경에서 폴더 내 수십 개 PDF를 벡터 인덱싱하여 자연어 질의 시 일치 페이지를 즉각 검색 및 하이라이트.
- **[I-03] 무손실 벡터 추출기 (Lossless Vector Ripper):**
  - PDF 내부의 베지에 곡선 및 드로잉 패스를 분리하여 CAD/일러스트 호환 순수 벡터 파일(`.svg`, `.dxf`)로 1초 만에 추출.
- **[I-04] 웹툰 롤 스티치 & 문맥 보존 슬라이스:**
  - **Stitch:** 다수 페이지를 여백 없이 세로로 이어 붙여 모바일용 무한 스크롤(Webtoon Roll) PDF 생성.
  - **Slice:** 긴 스크롤 PDF를 A4로 쪼갤 때 텍스트 줄이나 이미지 중간이 잘리지 않도록 여백을 감지해 자동 분할.
- **[I-05] 텍스트 완전 윤곽선화 (Convert Text to Outlines):**
  - 인쇄소 제출용으로 모든 글꼴을 순수 2D 벡터 도형으로 변환하여 타 PC에서의 폰트 유실/깨짐 원천 차단.
- **[I-06] AI 친화적 마크다운(.md) 초고속 추출:**
  - PDF의 제목, 본문, 표 구조를 온전히 보존하여 클립보드 복사 또는 `.md` 파일로 변환 (LLM 프롬프트 입력 최적화).
- **[I-07] 깨진 폰트 인코딩 수선 (ToUnicode Mapping Auto-Repair):**
  - 복사 시 외계어가 나오는 오래된 PDF의 폰트 CMap을 로컬 OCR과 대조하여 정상 UTF-8 텍스트로 내부 복구.

## 5. 실무 고효율 오피스 도구군

- **[O-01] 타겟 용량 맞춤 다이어터 (Target-Size Compressor):**
  - 공공기관(10MB) / 이메일(25MB) / 사용자 지정 목표 용량에 맞춰 DPI와 이미지 퀄리티를 역산하여 정밀 다이어트.
- **[O-02] 일련번호(Bates Stamping) & 목차 표지 자동 생성:**
  - 다수 문서 병합 시 기존 페이지 번호를 화이트아웃하고 통일된 연번 재부여 + 클릭 시 순간이동하는 하이퍼링크 목차(TOC) 표지 1장 자동 추가.
- **[O-03] 투명 배경 도장/서명 날인기:**
  - 스마트폰으로 찍은 도장 사진의 종이 배경을 투명하게 날려(Knockout) 원하는 서식에 찍고 로컬 암호화 금고에 보관.
- **[O-04] 비주얼 문서 비교 (Visual PDF Diff):**
  - 수정 전/후 문서를 겹쳐 삭제된 부분은 빨간색, 추가된 부분은 초록색으로 시각화하는 듀얼 뷰어.
- **[O-05] 손상된 PDF 구조 강제 복구 (Corrupted PDF Auto-Repair):**
  - XREF 테이블이나 트레일러가 유실되어 안 열리는 파일의 잔존 객체를 긁어모아 정상 PDF로 긴급 재패키징.
- **[O-06] 전역 로고/직인 일괄 교체 (Global Asset Swapper):**
  - 수백 개 PDF 문서에 박힌 구형 기업 로고/직인 이미지를 신규 고화질 이미지로 1:1 무손실 전역 스왑.
- **[O-07] 사진 보존 스마트 다크모드:**
  - 텍스트와 배경만 눈이 편한 다크 테마로 반전시키고, 사진/차트/도표는 원본 컬러를 유지하는 지능형 셰이딩.
- **[O-08] 무설치 플로팅 드롭존 (Staging Dock):**
  - 화면 구석에 작은 자석 드롭존을 띄워두고 이 폴더 저 폴더에서 파일을 던져 넣은 뒤 원클릭 일괄 병합.

## 6. 초저난이도 극가성비 유틸군 (PyMuPDF 1~10줄 완성)

- **[E-01] 2-Up 가로 책 스캔 낱장 분리:** 가로 1장에 2쪽이 들어간 스캔본을 좌/우 CropBox 분할로 A4 세로 1쪽씩 깔끔하게 재배열.
- **[E-02] 백지(빈 페이지) 자동 삭제:** 내용이 없는 백지 페이지를 일괄 탐색해 즉각 제거 (`len(text)==0 and len(images)==0`).
- **[E-03] 모바일용 여백 싹둑 자르기:** 사방의 흰 여백을 날리고 본문 바운딩 박스에 맞춰 페이지 크기를 축소해 가독성 극대화.
- **[E-04] 페이지 순서 1초 역순 뒤집기:** 거꾸로 스캔된 문서 순서를 한 줄 코드로 즉시 정상화 (`reversed(range(len(doc)))`).
- **[E-05] 300DPI 현재 페이지 클립보드 복사:** 캡처 도구 없이 단축키 한 번으로 현재 페이지를 초고화질 무손실 PNG로 복사.
- **[E-06] 지능형 페이지 분할:** `1-3, 5, 8-end` 범위 파서, 단일 추출, 낱장 분리, N장 단위 분할.
- **[E-07] 표 서식 보존 클립보드 주입:** PDF 표 드래그 복사 시 `HTML Table`과 `TSV` 포맷을 동시 주입해 엑셀/한글 표 서식 100% 유지.

## 7. OS 네이티브 퀵룩 및 배포 파이프라인

1. **Native OS QuickLook (`Spacebar`):** 탐색기에서 파일 선택 후 스페이스바 입력 시 0.05초 만에 초경량 팝업 뷰어 구동.
2. **프리뷰 내 Micro-Edit:** 뷰어 안에서 별도 무거운 창 로딩 없이 즉시 텍스트 복사, 마스킹, 회전을 끝내고 닫기.
3. **배포 인프라:**
   - `winget install Eoingtilab.EoingPDF` 매니페스트 구축.
   - 기업/관공서 무인 대량 배포용 Silent Install(`/S`) 스크립트.
   - SmartScreen 방어용 코드 서명 파이프라인(SignPath 등) 연동.
