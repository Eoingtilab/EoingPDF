# 어잉PDF 2.4.3

배포일: 2026-10-14 · Windows 10/11 x64

아이콘이 있는 버튼과 없는 버튼, 서로 다른 강조 색상이 섞여 있던 PDF 화면을 정리했습니다.

- 텍스트 작업 버튼을 같은 굵기·16px의 단색 선 아이콘으로 통일했습니다.
- 슬라이드쇼·직인·사본 저장을 다른 상단 버튼과 같은 중립 스타일로 맞췄습니다. 자주 쓰는 버튼의 위치와 단축키는 유지합니다.
- 직인·판서·캡처·변경 내역·전체 도구 창과 관련 메뉴에도 같은 아이콘을 사용합니다. 화살표·삭제 기호·색상 스와치가 이미 기능을 나타내는 곳에는 그림을 중복하지 않습니다.
- 현재 테마와 버튼 글자색에 맞게 아이콘을 그립니다. 비활성 버튼은 아이콘과 글자가 함께 흐려지고, 밝은 앱 테마의 슬라이드쇼에서도 고정 어두운 배경에 맞춰 표시합니다.
- 작은 창의 직인 안내와 버튼 줄을 분리했습니다. 버튼이 줄바꿈되어 글자가 잘리거나 안내가 PDF 영역을 가리는 문제를 줄였습니다.

세 언어·두 테마·작은 창과 125/150% 화면 배율에서 아이콘, 글자, 버튼 위치를 확인합니다. 설치형·포터블 상태 검사에도 실제 벡터 아이콘 렌더링을 포함합니다. PDF 처리와 편집 기록 동작은 2.4.2의 검증된 경로를 유지합니다.

[설계 범위와 검증 방법](ICON_UI_VALIDATION_2.4.3.md)을 기록했습니다. 실제 사용자 문서와 기존 설치 교체는 이번 검사에 포함하지 않습니다.
