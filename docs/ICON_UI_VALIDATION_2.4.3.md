# 2.4.3 PDF 도구 아이콘 정리

사용자 화면에서 일부 버튼만 아이콘을 사용하고 슬라이드쇼·직인·저장에 다른 강조가 적용된 점을 수정했습니다. 버튼 위치와 단축키는 유지하며 PDF 관련 작업을 같은 단색 선 아이콘으로 표시합니다.

## 변경 범위

- PDF 상단·하단의 텍스트 작업 버튼과 페이지·복사·인쇄·설정 메뉴.
- 직인 추가·보관함·삭제, 변경 내역 복원·되돌리기, 캡처 묶기·삭제·저장.
- 판서 도구 콤보와 지우개·선택·복구·삭제·이미지·붙여넣기·캡처·색 선택.
- 전체 도구 창의 추천 버튼, 실행·닫기와 모든 도구 항목.

50개 액션 기호를 16px 좌표계와 1.4px 선으로 그립니다. OS별 기본 아이콘·폰트 그림문자·외부 이미지 파일을 혼합하지 않습니다. 아이콘은 버튼의 현재 글자 팔레트를 읽어 테마와 비활성 상태를 따라가며, 어두운 발표 화면에서도 해당 화면의 글자색을 사용합니다. 이미지 캐시나 테마 신호 연결은 추가하지 않습니다.

슬라이드쇼·직인·사본 저장의 특별 강조를 제거했습니다. 전체 도구와 변경 내역의 실행 버튼도 중립 스타일로 맞췄습니다. 선택된 목록과 키보드 포커스, 현재 판서 모드의 상태 표시는 계속 유지합니다.

페이지 ▲/▼, 썸네일의 삭제 ×, PDF 미리보기 이미지, 색상 스와치와 기본 드롭다운 화살표는 이미 기능이나 값을 표시하므로 다른 그림을 겹치지 않습니다. 콤보·숫자 입력·체크박스의 값 표시에도 불필요한 장식은 추가하지 않습니다.

## 검증 방법

- 정상·비활성·선택 아이콘의 실제 픽셀, 현재 글자색, 투명 여백, 소유 위젯 삭제 후 안전한 렌더링을 확인합니다.
- 같은 아이콘 객체를 유지한 채 밝은 → 어두운 테마로 전환해 색이 바뀌는지 검사합니다.
- 세 언어·두 테마·960×820과 680×480 창, 별도 프로세스의 실제 Windows Qt 125/150% 배율을 검사합니다.
- 버튼의 아이콘·문구가 콘텐츠 공간 안에 들어가는지, 도구 항목의 줄바꿈과 메뉴 선택 상태에서 그림이 보이는지 확인합니다.
- 작은 영어 창에서 직인 안내가 세로로 길어져 PDF 영역을 가리고 삭제 버튼 문구가 잘리는 문제를 재현했습니다. 안내를 전체 폭의 별도 줄로 두고 조작 버튼은 자연스럽게 줄바꿈합니다.
- 복원 버튼의 비활성 글자가 밝은 배경에서 흰색이 되는 문제를 확인하고, 기본 중립 버튼 스타일을 사용하도록 수정했습니다.
- 밝은 테마 메뉴의 선택 행에서 어두운 글자·아이콘이 파란 배경과 겹쳐 흐려지는 문제도 재현했습니다. 선택된 메뉴는 글자와 아이콘을 함께 밝게 표시합니다. 일반 버튼·콤보·목록의 아이콘 색상은 기존 상태별 팔레트를 유지합니다.
- 기존 도구·직인·판서·복구·캡처·다국어 동작 회귀와 전체 배포 검사를 수행합니다. 설치형·포터블 상태 검사에서 실제 아이콘 픽셀을 그려 벡터 엔진 포함 여부도 확인합니다.

재현 명령은 `tests/icon_ui_smoke.py --scale 1.25`, `--scale 1.5`입니다. 결과 JSON과 자기 창만 캡처한 그림은 `temp/icon-ui-validation/1.25`, `1.5`에 남깁니다. 개인 문서·사용자 데스크톱이나 다른 앱을 캡처하지 않습니다. 라이선스 확인은 시험 게이트로 처리합니다.

통합 검사 중 다른 시험 창이 활성화되면 기본 팝업 메뉴가 닫혀 화면 검사가 중단되는 조건을 자체 경쟁 창으로 재현했습니다. 메뉴 색상 검사는 시험 메뉴만 포커스를 가져가지 않는 창으로 잠시 표시해 안정화합니다. 같은 QMenu 렌더러·선택 항목·실제 픽셀 대비 검사를 유지하고, 앱의 메뉴 창 플래그나 동작은 바꾸지 않습니다.

최종 배포의 검사 수·변경 파일·두 실행파일의 해시·실제 공개 다운로드 확인은 [공식 검증 기록](https://github.com/Eoingtilab/nalapps-releases/blob/main/products/eoingpdf/2.4.3/validation.json)에 보존합니다. 이 수정은 PDF 작업 화면과 관련 도구 창의 일관성에 관한 것이며, 전체 앱의 모든 대화상자나 모든 PDF 문서의 호환성을 보장하는 검증은 아닙니다. 사용자별 실제 문서와 기존 설치 교체는 이번 검사에 포함하지 않습니다.
