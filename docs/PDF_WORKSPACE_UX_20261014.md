# PDF 작업 화면 개선 계획 · 2.4.0

## 해결할 불편

기존 화면은 페이지 이동·발표·직인·저장·보조 도구가 같은 줄에 섞이고, 수십 개 도구가 하나의 긴 메뉴에 나열되어 작은 화면에서 찾기 어렵다. PDF 효과를 현재 화면에 적용해도 되돌리는 방법이 없어 확인과 수정이 끊긴다.

## 화면과 작업 흐름

- 첫 줄: PDF 열기 → 슬라이드쇼 · F5 → 직인·서명 넣기 → 모든 도구 → 사본 저장 → 닫기. 발표와 직인은 상시 표시하고 서로 다른 강조 색과 설명을 제공한다.
- 둘째 줄: 실행 취소 → 다시 실행 → 변경 내역 → 양식 입력 → 페이지 정리 → 복사·보기. 페이지 삭제와 앞/뒤 이동은 페이지 정리 메뉴에 모은다.
- 중앙: 페이지 축소판과 현재 PDF. 아래에는 페이지 이동·배율·인쇄 준비, 맨 아래에는 상태와 설정을 배치한다.
- 모든 도구: 검색, 작업 분류, 짧은 설명, 추천 도구. 35개 변환 도구와 발표·양식·복사·목록 전환을 같은 목록에서 찾는다. 기존 긴 목록을 도구 설정 창에도 반복하지 않는다.
- 작업 분류: 직인·워터마크·양식, 페이지 정리, 스캔·문자 인식, 보안·개인정보, 보기·발표·인쇄, 복사·내보내기, 압축·복구.
- PDF 결과 도구는 **현재 PDF에 적용**이 기본이다. 적용 → 화면 확인 → 실행 취소 또는 추가 편집 → 사본 저장으로 연결한다. ZIP·Markdown 등은 내보내기로 파일을 저장한다.
- 대상 문서는 원래 파일명으로 보여 준다. 내부 임시 파일 경로는 작업 화면에서 숨긴다.

## 취소와 복구

- 페이지 순서/삭제, 직인 추가/위치/크기/삭제, 워터마크 등 PDF 효과와 양식 입력을 같은 저장 전 기록에서 되돌린다.
- 실행 취소 Ctrl+Z, 다시 실행 Ctrl+Y / Ctrl+Shift+Z. 버튼 설명에 되돌릴 작업 이름을 표시한다.
- 변경 내역에서 원하는 상태로 돌아가거나 모든 변경을 문서를 열었을 때 상태로 되돌린다. 전체 되돌리기 자체도 실행 취소할 수 있다.
- 새 문서를 열거나 사본 저장을 완료하면 그 문서로 새 기록을 시작한다. 이미 저장된 타 프로그램의 워터마크를 판별해 지우는 기능은 별도 범위다.
- 기록은 최대 32개 편집 단계를 유지한다. 임시 PDF와 이미지 참조는 사용 중인 기록·다시 실행·현재 초안에서 안전하게 보유하고, 필요 없어진 작업 또는 창 종료 후 정리한다. 원본 PDF와 기존 출력은 덮어쓰지 않는다.
- 도구 창을 취소했을 때 기존 직인을 계속 선택·수정할 수 있도록, 도구용 PDF 사본 생성과 화면의 편집 상태를 분리한다.

## 참고 근거

Adobe의 [새 Acrobat 구성 설명](https://helpx.adobe.com/acrobat/learn-new-acrobat.html)은 작업 흐름에 따라 도구를 모으고 전역 바에 실행 취소·다시 실행을 배치한다. 이번 화면은 이런 분류·접근 원칙을 사용자의 발표·직인 작업에 맞춰 적용한다.

NESPDF의 [작업 영역](https://www.nespdf.com/help/kor/work_area.htm)과 [실행 취소·다시 실행](https://www.nespdf.com/help/kor/undo_and_redo.htm)은 작업별 리본과 빠른 실행 도구를 설명한다. PDF-XChange의 [공식 V10 화면 안내](https://help.pdf-xchange.com/pdfxe10/explore-the-user-interface_ed.html)는 빠른 실행 취소·다시 실행과 도구 이름 검색을 제공한다. 이 배치는 메뉴의 기능 수를 줄이지 않으면서 찾는 경로를 짧게 하는 참고 근거다.

## 확인 기준

- 680×480 작은 창, 기본 창, 한국어·영어·일본어, 밝은/어두운 테마에서 필수 버튼과 PDF 작업 영역이 겹치지 않는다.
- 도구 분류에 모든 변환 키가 한 번씩 존재하고, 검색/선택/빈 결과/키보드 동작이 정상이다.
- 실제 생성 PDF에 워터마크와 양식 값을 적용한 뒤 실행 취소·다시 실행하고, 페이지 순서와 직인 초안을 함께 복구한다.
- 실패한 적용, 취소한 도구, 기록 분기, 기록 제한, 저장 후 임시 파일 정리와 원본 바이트 보존을 확인한다.
- 저장한 양식의 실제 필드 트리와 위젯 값, 암호 문서의 암호 유지, Windows 화면과 배포 실행파일을 검증한다.

검사 결과와 배포 파일 해시는 버전별 릴리스 검증 기록에 남긴다.
