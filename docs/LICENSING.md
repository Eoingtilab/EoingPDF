# 라이선스 설정

어잉PDF는 무료 라이선스를 활성화한 뒤 사용할 수 있습니다.
서버: `https://app.nal.la/`, EDD 상품 ID: **26818 (어잉PDF)**.

설치 과정 또는 앱/뷰어의 라이선스 설정에서 키를 입력하고 **활성화 / 재활성화**를 누릅니다.
**비활성화**는 이 PC의 활성화를 서버에서 해제합니다. 보관된 같은 키로 다시 활성화할 수 있습니다.
키를 교체하려면 기존 라이선스를 먼저 비활성화합니다. 프로그램 제거와 라이선스 비활성화는 별개입니다.
다른 PC로 이동하기 전 라이선스 설정에서 비활성화해 주세요.

최초 활성화에는 인터넷이 필요하며, 성공한 활성화 상태는 DPAPI로 보호하여 저장합니다.
이후에는 앱을 다시 실행하거나 PC를 재부팅해도 오프라인 사용이 가능합니다. 오프라인 사용 기간 제한은 두지 않습니다.
상태 확인·비활성화·재활성화·업데이트에는 인터넷이 필요합니다. 연결 실패는 기존 활성화를 해제하지 않으며, 미인증 PC에 사용 권한을 새로 부여하지도 않습니다.
서버에서 명시적인 만료·취소·정지 응답을 받은 경우 로컬 활성화를 해제합니다. 오프라인 중 서버의 취소를 즉시 확인할 수는 없습니다.
인증되지 않은 설치도 파일 설치 자체는 가능하지만 프로그램 기능은 활성화 전 사용할 수 없습니다.
무인 설치에서는 키 입력창을 생략하고 첫 실행에 활성화를 요구합니다.

키는 Windows DPAPI로 현재 사용자만 복호화하도록 `%LOCALAPPDATA%\EoingPDF\license\license.dat`에 저장합니다.
키와 임의로 만든 PC 식별자, 상품 ID를 HTTPS POST로 서버에 전송합니다.
기기 이름, 하드웨어 일련번호, PDF와 문서 내용은 보내지 않습니다. 키를 명령줄·URL·로그에 남기지 않습니다.
인증 정보는 배포 파일과 소스 ZIP에 포함하지 않습니다.

연동 규격: [EDD Software Licensing API](https://easydigitaldownloads.com/docs/software-licensing-api/).
활성화·확인·비활성화 응답을 검증하며 다른 상품 응답, 연결 오류, 만료/정지된 키는 거부합니다.

## 2026-09-16 실제 연결 확인

현재 Windows 사용자에 저장된 등록 상태를 키 값 출력 없이 확인했다. 실제 서버 check_license 결과는 success=true, license=valid, item_id=26818이었다. 같은 저장 상태를 새 프로세스에서 읽고 통신 함수를 사용하지 않는 조건에서도 valid_session=true, 통신 호출 0회를 확인했다. 이번 검사는 실제 비활성화·재활성화 왕복이나 PC 재부팅을 수행한 것은 아니다.

실제 get_version 응답은 new_version이 빈 문자열이고 다운로드 링크는 있으나 sha256이 없었다. 따라서 현재 응답만으로 자동 업데이트를 적용할 수 없다. 서버의 상품 버전과 Windows 설치 EXE, 그 EXE의 SHA-256 연결이 필요하다. EDD 기본 API의 버전·다운로드 응답 형식은 공식 문서 https://easydigitaldownloads.com/docs/software-licensing-api/ 를 따른다. SHA-256은 이 앱의 추가 검증 필드이며 서버 구현에서 제공해야 한다.

읽기 전용 재확인은 scripts/check_edd_connection.py --online으로 수행한다. 출력은 등록 여부, 상품 일치, 버전 형식과 해시 존재 여부로 제한하며 라이선스 키·기기 ID·서명된 다운로드 URL을 출력하지 않는다. 라이선스 등록 상태를 변경하지 않는다.
