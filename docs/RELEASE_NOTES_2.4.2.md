# 어잉PDF 2.4.2

배포일: 2026-10-14 · Windows 10/11 x64

50페이지 이하의 일상 문서 작업을 중심으로, 양식 데이터 보존과 취소 동작을 보완했습니다.

- 역순·페이지 추출·분할 후에도 여러 페이지에 표시되는 공유 입력 필드를 유지합니다.
- 한 페이지에 반복 표시되는 같은 필드는 입력창 하나로 편집합니다. 부모에서 상속받은 선택 목록과 다중 선택의 저장값·표시도 보완했습니다.
- 긴 한글 입력과 많은 입력 칸을 처리하는 작업 통신 한도를 늘렸습니다.
- 앞쪽 페이지를 삭제해도 보고 있던 페이지를 유지합니다. 판서 종료를 취소하면 PDF 창과 미저장 편집도 유지합니다.
- 썸네일 카드 최대 24개로 이미지 누적을 제한하고, 닫힌 창의 문서 이미지·타이머를 정리합니다.

직인, 워터마크, 양식 입력, 페이지 편집, 실행 취소와 저장을 연결해서 검사합니다. 원본 파일을 유지하고 저장된 필드값·화면 표시·링크·회전·자르기를 확인합니다. 1,000페이지 일반 시험 문서에서는 프로세스 작업 집합이 약 249MB에서 119MB로 줄었습니다. 이 수치는 생성한 문서의 동일 조건 비교이며 모든 PDF의 메모리나 속도를 보장하지 않습니다.

2.4.1의 페이지 화살표 수정과 2.4.0의 작업별 도구 검색·직인·변경 내역 기능을 포함합니다. [검증 조건과 범위](QUALITY_REPORT_2.4.2.md)를 기록했습니다. 실제 사용자 문서와 기존 설치 교체는 이번 검사에 포함하지 않습니다.
