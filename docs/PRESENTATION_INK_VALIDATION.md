# 발표 판서 입력·저장 검증

2026-09-14 소스 검증. 배포 설치 파일은 이번 변경으로 다시 빌드하지 않았습니다.

## 결함과 변경

- `QTest.mousePress`로 판서 시작 시 슬라이드가 0에서 1로 이동하는 결함을 먼저 재현했습니다. 캔버스의 왼쪽 판서 입력은 페이지 이동 필터가 소비하지 않도록 수정했습니다.
- 화면 전체가 아닌 중앙 PDF 픽스맵의 논리 좌표 영역으로 정규화합니다. 여백에서 시작하는 입력과 B/W 상태의 입력은 판서를 만들지 않습니다.
- 슬라이드별로 판서를 보관하며 페이지 이동·창 크기 변경 후 복원합니다.
- 저장 시 뷰어에서 남긴 페이지 순서를 적용하고 회전 역행렬로 PDF Ink 주석을 생성합니다. 원본 암호화를 유지합니다.
- 같은 디렉터리에 임시 문서를 완성·재개방한 후 하드 링크로 게시합니다. 저장 중 다른 파일이 같은 이름으로 생성되어도 덮어쓰지 않습니다. 하드 링크 미지원 파일시스템에서는 오류를 표시하며 판서를 유지합니다.
- 저장 후에는 저장된 문서를 기준으로 계속 발표합니다. 후속 저장에서 이전 판서가 사라지지 않도록 했습니다.
- Esc·창 닫기·발표자 창 닫기에 한글 저장/저장하지 않음/취소를 제공합니다. 저장 대화상자를 취소해도 발표를 종료하지 않습니다.

## 실행 증거

`QT_QPA_PLATFORM=offscreen`에서 다음을 실행했습니다.

- `python -m pytest tests/test_presenter_ink.py -q -p no:cacheprovider`: 13개 통과. 실제 Qt 입력 전달, 0/90/180/270도 회전과 비영점 CropBox의 저장 좌표, 암호화 문서, 원본 바이트 보존, 표시 페이지 선택, 1/1.5/2 배율, 파일명 경쟁, 종료 취소를 검사합니다.
- `python tests/viewer_smoke.py`: 뷰어·삭제·저장 취소·슬라이드쇼 탐색 및 종료 검사 통과.
- `python tests/presenter_ui_smoke.py`: HUD·그리드·커튼·스포트라이트·레이저 검사 통과. offscreen의 겹친 창에 대한 커서 라우팅 때문에 스포트라이트 검사가 처음 실패했습니다. HUD에 MouseMove를 명시적으로 전달하고 좌표와 밝기 검사를 유지했습니다. 물리 마우스 실기기 검증으로 해석하지 않습니다.

## 남은 검증과 구현

위 기록은 기본 Qt 판서 구현 시점의 검증입니다. 이후 Direct2D GPU 합성과 형광펜/고스트 잉크/도형 보정/라이브 텍스트가 추가됐습니다. 지속 120fps, 장시간 판서 메모리 제한, 실제 듀얼 4K 환경 검증은 미완료입니다. 이 문서는 전체 제품 완성이나 국제표준 인증을 주장하지 않습니다.

## 형광펜과 고스트 잉크

- 도구 목록 또는 `P`로 펜을 사용합니다. `H`는 텍스트 줄 형광펜입니다. 드래그 영역과 겹치는 텍스트 줄 전체에 맞춰 영역을 생성합니다. OCR 텍스트가 없는 스캔은 줄을 인식하지 못합니다.
- `Ctrl+P`는 임시 펜입니다. 입력을 마친 뒤 3초 동안 유지하고 0.6초 동안 흐려진 뒤 삭제합니다. 작성 중인 선은 사라지지 않으며, 임시 펜만 남으면 종료 시 저장 확인을 띄우지 않습니다.
- 펜/형광펜은 색·너비·불투명도를 획별로 유지합니다. Qt와 GPU/DC 모두 혼합 스타일을 그립니다. 형광펜은 PDF Highlight 주석으로, 펜은 Ink 주석으로 저장합니다. 고스트 잉크는 저장하지 않습니다.
- 저장과 종료 시 원본 보존·암호 유지·기존 파일 거부 정책은 그대로 적용합니다.

검증: `test_ink_tools.py`, `test_native_ink.py`, `test_presenter_ink.py` 합계 36개 통과. H/Ctrl+P 키와 Qt 드래그로 줄 선택, 네 방향 회전 및 CropBox 저장 좌표, 원본 바이트 보존, 고스트 시간별 투명도와 타이머 종료, 저장 제외를 확인했습니다. GPU/DC 혼합 스타일과 투명도 변경 시 캐시 갱신도 검사합니다. `native_ink_ui_smoke.py`의 실제 Windows 창 연결 검사도 통과했습니다. 물리 입력·다단 실문서·실제 고주사율 화면 검사는 별도입니다.

## 손그림 도형 보정

도구 목록의 ‘도형 보정’ 또는 `Ctrl+D`로 켭니다. 그리기를 마치면 원·사각형·화살표·별·체크 후보를 검사하고, 기하 오차와 경로 길이·꼭짓점 커버리지가 허용 범위 안일 때 보정합니다. 일반 펜·형광펜·임시 펜 모드에서는 자동 보정하지 않습니다. 불확실한 선과 작은 필기는 원래 좌표로 남깁니다.

계산은 정규화된 화면 비율이 아닌 PDF 페이지의 실제 가로·세로 단위에서 수행하므로 가로 페이지에서도 원이 타원으로 변하지 않습니다. 보정 결과는 기존 GPU/DC 렌더러와 PDF Ink 벡터 주석 저장 경로를 사용합니다.

`test_shape_snap.py` 25개 통과: 5개 도형의 흔들림과 역방향 입력, 회전된 사각형/화살표/별, 교차형 별, 낙서·직선·작은 선·열린 모양 거부, 잘못된 입력, 실제 Qt 드래그 및 네 방향 PDF 저장 시 원의 가로·세로 지름 일치를 검사합니다. 기존 형광펜·기본 판서 검사와 함께 43개가 통과했습니다. 합성 입력으로 확인한 범위이며 다양한 사람의 필체와 실제 펜 장치에 대한 인식률은 아직 측정하지 않았습니다.

## 라이브 텍스트 (2026-09-15)

`T` 도구에서 페이지를 클릭하거나 텍스트가 없는 페이지 여백을 더블클릭하면 입력창을 엽니다. Enter는 적용, Esc는 취소입니다. 여백 한 번 클릭은 운영체제의 더블클릭 구분 시간이 지난 후 페이지를 넘깁니다. 방향키 탐색은 이 대기를 사용하지 않습니다.

배경의 밝기를 표본 추출하여 검정 또는 흰색 글자를 선택합니다. Pretendard로 한 번에 256자까지 입력하며, 페이지 너비에 맞춰 저장 글자를 줄바꿈합니다. 공간이 부족하면 안내와 입력 내용을 유지하고 페이지 이동·저장을 중단합니다. 입력 중에는 네이티브 오버레이를 숨겨 IME/입력창이 마우스를 받고, 적용 후 GPU 렌더링으로 돌아갑니다.

글자는 글꼴 윤곽을 가진 Polygon 벡터 주석으로 저장합니다. 첫 윤곽 주석의 내용에 입력 문자열도 보관합니다. 이는 검색 가능한 PDF 본문이나 수정 가능한 FreeText 필드를 생성하는 방식이 아닙니다. O와 한글처럼 속이 빈 글자 윤곽을 유지하며 원본 파일은 변경하지 않습니다.

`test_ink_text.py` 11개 통과: 밝고 어두운 배경×네 방향 회전, 한글 IME 커밋 메시지, Enter 탐색 충돌 방지, 줄바꿈·넘침·취소, 더블클릭 탐색 취소, 글자 구멍과 PDF 저장을 검사합니다. Windows GPU UI 검사에서 네이티브 T 입력→한글 입력→GPU 렌더링 복귀도 통과했습니다. 실제 물리 키보드 IME의 전체 조합 과정과 보조 모니터 검증은 별도입니다.

이 과정에서 진단 프로세스가 삭제된 뒤 Qt 콜백에서 접근하던 정리 오류도 수정했습니다. `test_sniffer_lifecycle.py` 2개와 기존 `viewer_smoke.py`가 통과했습니다.


## B/W 칠판 저장 (2026-09-15)

B/W는 슬라이드별 검은/흰 칠판으로 전환한다. P/T 등으로 작성한 내용은 슬라이드 판서와 별도로 유지한다. 같은 키 또는 Space로 돌아오며, 창 크기가 달라져도 최초 칠판의 종횡비와 좌표를 유지한다. 저장할 내용이 있는 칠판만 해당 슬라이드 뒤에 검은색, 흰색 순으로 PDF 페이지를 추가한다. 빈 칠판과 임시 펜만 있는 칠판은 제외한다. 저장 후 새 문서에서 발표를 계속하며 반복 저장으로 기존 칠판이 사라지지 않는다. 원래 뷰어로 돌아갈 때는 칠판 소유 슬라이드로 이동한다. 칠판에는 PDF 텍스트 줄이 없으므로 H의 텍스트 줄 흡착은 적용되지 않는다.

- `test_presentation_boards.py` 3개: 일반/암호 문서에서 실제 Qt 필기·칠판 전환·크기 변경·페이지 이동·두 차례 저장, 페이지 순서·배경 픽셀·주석 수·원본 보존, 빈/임시 판서 제외, 잘못된 크기의 원자적 저장 실패.
- 칠판/기존 판서/라이브 텍스트 통합 27개 통과. 형광펜/도형/네이티브 엔진 회귀 48개 통과.
- Windows `native_ink_ui_smoke.py`: GPU 칠판 입력과 슬라이드 판서 분리·복원, 한글 입력과 HWND 해제 통과. `viewer_smoke.py` 기존 뷰어 흐름 통과.
- 물리 펜, 실제 듀얼 4K 화면, 배포 설치본에서의 검증을 대신하지 않는다. 최종 설치본은 아직 이 변경으로 재빌드하지 않았다.
