# 어잉PDF 2.4.7

PDF 뷰어를 왼쪽 작업별 도구 목록, 가운데 문서, 오른쪽 페이지 이동·확대 조작으로 정리했습니다. 페이지 목록을 오른쪽에서 열고 닫을 수 있으며, 보기 전환을 실행하면 닫힌 목록도 함께 열립니다.

슬라이드쇼와 직인·서명은 상단에서 바로 실행합니다. Ctrl+O로 PDF를 열고 Ctrl+마우스 휠로 확대·축소할 수 있습니다. 기존 기능과 무료 라이선스 방식은 유지하며, 편집 결과는 원본을 보존하는 사본으로 저장합니다.
