# 어잉PDF 2.4.0

배포일: 2026-10-14 · Windows 10/11 x64

## 작업별로 정리한 PDF 화면

상단에 **슬라이드쇼 · F5**와 **직인·서명 넣기**를 고정하고, 편집 도구와 파일 저장을 정리했습니다. **모든 도구**에서 이름을 검색하거나 7개 작업 분류를 선택하세요. 기존 긴 도구 메뉴를 없애고 짧은 설명과 추천 기능으로 바꿨습니다. 페이지 삭제·순서 변경은 **페이지 정리**, 이미지·표 복사와 목록 전환은 **복사·보기**에 모았습니다.

## 적용 후 바로 실행 취소

문구·PNG 워터마크, PDF 효과와 양식 입력을 **현재 PDF에 적용**해 먼저 확인하세요. 상단 **실행 취소**와 **다시 실행**으로 변경을 되돌리거나 다시 적용하고, 마지막에 **사본 저장**으로 저장합니다. 직인 추가·이동·크기·삭제와 페이지 순서·삭제도 같은 기록에서 복구합니다.

**변경 내역**에서 이전 상태를 선택하거나 **모든 변경 되돌리기**로 처음 열린 상태로 돌아갈 수 있습니다. 전체 되돌리기 자체도 실행 취소할 수 있습니다. 도구 창을 취소해도 원래 직인은 계속 선택·수정할 수 있습니다.

단축키: Ctrl+Z 실행 취소, Ctrl+Y / Ctrl+Shift+Z 다시 실행, Ctrl+Shift+T 모든 도구, Ctrl+S 사본 저장, F5 슬라이드쇼.

## 보존과 검증

원본과 기존 결과를 덮어쓰지 않습니다. 저장 전 기록은 최대 32개 편집 단계이며, 새 문서 열기·사본 저장 완료 후 새 기록을 시작합니다. 다른 앱에서 이미 저장된 워터마크를 자동으로 식별해 제거하는 기능은 별도 범위입니다.

실제 PDF의 워터마크·양식 값·페이지·직인을 적용/복원하고, 암호와 실제 양식 필드 구조를 검증합니다. 3개 언어, 2개 테마, 680×480/960×820 크기의 Windows 화면과 도구 검색·변경 내역·직인 화면을 확인합니다. 배포 실행파일의 상태 검사에 JPG와 PDF 실행 취소·도구 검색도 포함했습니다.

물리 펜·프린터·다중 모니터, 사용자별 원본 PDF와 실제 기존 설치 교체는 별도 인수 시험을 수행하지 않았습니다.
