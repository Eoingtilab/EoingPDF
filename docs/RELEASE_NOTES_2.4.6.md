# 어잉PDF 2.4.6

PDF 뷰어를 왼쪽 도구 패널과 중앙 문서 영역으로 정리했습니다. 자주 쓰는 슬라이드쇼와 직인·서명은 상단에서 실행할 수 있습니다. 페이지 목록과 편집 도구 패널은 각각 열고 닫을 수 있습니다.

기존 Ctrl+마우스 휠 확대·축소와 하단 배율·페이지 이동 조작은 계속 사용할 수 있습니다. 원본 PDF를 보존하며 편집 결과는 사본으로 저장합니다.
