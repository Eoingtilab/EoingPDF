## License activation

EoingPDF uses app.nal.la (EDD Software Licensing) for license activation, validation, and deactivation. During these operations the app sends the license key, EoingPDF product ID, and a randomly generated EoingPDF device identifier. The device identifier is not derived from hardware serial numbers, Windows account names, IP addresses, or document contents.

## Updates

Unpackaged editions check a public GitHub-hosted release manifest and download verified release assets from the Eoingtilab/nalapps-releases repository. Downloaded update files are verified with SHA-256 before installation. Microsoft Store editions use Microsoft Store-managed updates instead of the built-in updater.

## Local data

Depending on the features used, EoingPDF may store local settings, encrypted license state, update backups, search indexes, and reusable stamp/signature images under the current Windows user's local application data folder. These files remain on the PC unless the user explicitly exports or moves them.

## No advertising or document analytics

EoingPDF does not include advertising SDKs and does not upload document contents for analytics, advertising, or AI training.

## Third-party services

- app.nal.la: license activation and entitlement checks.
- GitHub (Eoingtilab/nalapps-releases): public release metadata and update files for non-Store editions.
- Microsoft Store: distribution and updates for the Microsoft Store edition.

These services process network metadata according to their own policies when the user connects to them.
