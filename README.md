# 어잉PDF 2.2.0

**탐색기 우클릭으로 변환·병합·요약하고, 가볍게 열어보는 Windows PDF 유틸리티.**

[릴리스 다운로드](https://github.com/Eoingtilab/EoingPDF/releases) · [무료 라이선스 발급](https://app.nal.la/?p=26818) · [변경 이력](CHANGELOG.md)

| 항목 | 내용 |
|---|---|
| 운영체제 | Windows 10/11 x64 |
| 배포 | 설치 EXE / 포터블 ZIP |
| 사용 조건 | 무료 라이선스 활성화 필요 |
| 라이선스/업데이트 | app.nal.la · EDD 상품 26818 (어잉PDF) |
| 디자인 | Pretendard, 제공된 앱/문서 아이콘 |
| 문서 처리 | 로컬 처리, 원본 보존 |

GitHub 저장소와 릴리스가 비공개이면 접근 권한이 있는 계정으로 로그인해야 합니다.

탐색기 우클릭으로 문서를 PDF로 바꾸고, 하나로 합치고, 핵심문장을 빠르게 꺼내는 Windows 포터블 유틸입니다.
메인 앱을 먼저 열 필요가 없습니다. 파일은 외부로 전송하지 않고 원본도 수정하지 않습니다.

## 시작

무료 이용도 app.nal.la의 **어잉PDF 라이선스(상품 26818)**를 활성화해야 합니다.
설치 과정 또는 앱/뷰어의 **라이선스 설정**에서 키를 입력해 활성화하며, 비활성화 후 재활성화할 수 있습니다.
최초 활성화에는 인터넷이 필요하며 이후에는 오프라인에서도 사용할 수 있습니다. 키는 PC에 암호화 저장하고 문서 내용은 서버로 보내지 않습니다.

설치형은 `EoingPDF-2.2.0-Setup-x64.exe`를 실행합니다. 현재 사용자 폴더에 설치되며 시작 메뉴와 우클릭 메뉴, PDF 문서 아이콘을 등록합니다.
설치 마지막 화면에서 기본 PDF 앱 설정을 열 수 있습니다. 제거는 Windows 설정의 설치된 앱에서 **어잉PDF**를 선택합니다.
아래는 포터블 사용 방법입니다.

1. `release/EoingPDF-2.2.0-portable.zip`을 원하는 위치에 풉니다. 현재 2.2.0은 확장 기능 통합 검증 중인 개발 빌드입니다.
2. 폴더 안의 `install-context-menu.cmd`를 한 번 실행합니다. 관리자 권한은 필요하지 않습니다.
   Windows 기본 앱 설정이 열리면 `.pdf`에 **어잉PDF**를 선택합니다. 이후 PDF를 더블클릭하면 뷰어가 열립니다.
3. 탐색기에서 파일을 선택하고 우클릭합니다. Windows 11에서는 **더 많은 옵션 표시**를 누릅니다.
4. **어잉PDF · PDF로 변환 / 하나로 합치기 / 핵심문장 요약**을 선택합니다.

작은 진행창에서 자동 작업합니다. 결과는 원본 폴더에 새 이름으로 저장됩니다.
서로 다른 폴더의 파일을 합치면 첫 파일의 폴더에 저장합니다. 병합 순서는 탐색기가 전달한 선택 순서이며,
정확한 순서를 지정하려면 `EoingPDF.exe`에서 목록을 정렬하세요.
포터블 폴더를 이동했다면 우클릭 메뉴를 다시 등록하세요. 제거하려면 `uninstall-context-menu.cmd`를 실행합니다.


### 증빙 보정·개인정보 지우기 (2026-09-17 통합 빌드 포함)

**암호·보조 도구 → 증빙 보정·개인정보 지우기**에서 PDF를 선택하면 기울기와 종이 그림자를 보정한 뒤, 텍스트 및 Windows OCR로 인식한 개인정보 영역을 실제 삭제합니다. 결과는 300DPI 이미지 PDF이며 원본은 유지합니다. 완료 후 **원본과 비교**에서 좌우 슬라이더로 결과를 확인할 수 있습니다. OCR 언어팩이 필요하며 인식 실패나 취소 시 결과를 게시하지 않습니다.

OCR이 개인정보를 모두 찾는 것은 아닙니다. 흐린 글자, 복잡한 배경, 여러 줄로 끊어진 번호는 누락될 수 있으므로 제출 전에 확인해야 합니다. 그림자 보정은 사진·색상을 바꿀 수 있고 결과의 텍스트 검색·원본 양식·전자서명은 유지되지 않습니다.

### 인쇄용 PDF 준비

뷰어 아래 **인쇄 준비**에서 **밝은 인쇄용 사본**, **4쪽 모아찍기**, **소책자 인쇄 배치**를 선택합니다. 새 PDF를 만든 뒤 원하는 프린터에서 출력하세요. 밝은 사본은 어두운 배경이 대부분인 페이지의 무채색 배경·글자를 바꾸며 삽입 이미지와 유색 도형을 유지합니다. 원래 밝은 페이지와 전체가 이미지인 스캔 슬라이드는 반전하지 않습니다. 결과는 이미지 PDF로 저장되어 텍스트 검색이 사라지므로 원본과 비교해 확인하세요.

## 지원 기능

- PDF · 이미지 · Office · 한글 · 텍스트를 혼합하여 PDF 병합
- 문서별 PDF 변환, 페이지 출처가 붙는 오프라인 핵심문장 요약
- 페이지 추출/삭제/순서 변경, 회전, 무손실 최적화
- PDF → PNG ZIP, 텍스트 추출, 페이지 번호
- 파일 드롭, 순서 이동, 페이지 미리보기, 중단, 결과 폴더 열기
- 독립 PDF 뷰어: 페이지 이동, 확대/너비 맞춤, PDF 파일 열기
- 왼쪽 작은 페이지 미리보기 클릭으로 이동. 각 미리보기의 **X → 삭제 확인**으로 페이지 제거
- 삭제는 임시 편집 상태로 유지. **저장 / Ctrl+S**를 눌러 새 PDF 저장. 원본 보존
- **페이지 삭제**에서 `3, 7-9`처럼 여러 페이지를 함께 지정할 수도 있음
- **슬라이드쇼 / F5**: 현재 페이지부터 전체화면. Space/→/↓/왼쪽 클릭은 다음, ←/↑/오른쪽 클릭은 이전, Home/End는 처음/끝, Esc 종료
- 전체화면 오른쪽 위 **전체화면 종료** 또는 **F5**로도 뷰어로 돌아옵니다. 뷰어의 **닫기** 버튼으로 창을 닫습니다.

앱 왼쪽 **PDF 열어보기**로 바로 읽을 수 있습니다. PDF를 `EoingPDF.exe`에 끌어 놓거나 연결 프로그램으로 열어도 뷰어가 실행됩니다.
**설정 · 라이선스 · 업데이트 → 일반 → 우클릭 메뉴·기본 PDF 앱 설정**에서 기본 뷰어 선택 화면을 다시 열 수 있습니다.
Windows의 기본 앱 선택은 Windows 설정에서 확인하며, 앱이 기존 연결을 강제로 덮어쓰지 않습니다.

### 화면 테마와 언어

**설정 · 라이선스 · 업데이트 → 일반 → 화면 테마**에서 시스템 설정 따름 / 밝게 / 어둡게를 선택합니다.
창과 컨트롤에 바로 반영되며 PDF 원본 색상과 발표 화면의 문서·판서 색상은 유지합니다.
UI와 우클릭 작업 진행창은 Windows 표시 언어에 따라 한국어·영어·일본어를 사용합니다. 일부 고급 도구와 오류 문구 번역은 정리 중입니다.

Windows 11의 지원 버전에서는 기본 창 프레임에 Mica, 대화상자 프레임에 Acrylic을 요청합니다.
투명 효과 끄기·고대비·원격 세션·배터리 절약 모드에서는 단색으로 표시합니다. 문서와 Qt 콘텐츠 영역은 불투명하게 유지합니다.
이 기능은 공통 SDK 색상에 기반한 Qt 어댑터이며 SDK 자체의 공식 다크 리소스는 아닙니다.

### 캡처 이미지를 PDF로 묶기 (2026-09-17 통합 빌드 포함)

메인 창 또는 PDF 뷰어를 열어 둔 상태에서 `Win+Shift+S`로 캡처하거나 이미지를 클립보드에 복사하세요.
서로 다른 이미지가 2개 이상 모이면 **캡처 N개 · PDF로 묶기** 버튼이 나타납니다.
버튼을 누르면 미리보기 목록에서 드래그로 순서를 바꾸거나 이미지를 제외할 수 있습니다.
**PDF 저장**은 이미지 하나당 한 페이지로 저장하며, 기존 파일을 덮어쓰지 않습니다.
**캡처 모두 비우기**로 메모리의 수집 목록을 지울 수 있습니다.

앱이 열리기 전의 클립보드 기록은 읽지 않습니다. 열린 앱 창이 없으면 수집을 중단하고 모은 이미지를 지웁니다.
수집은 메모리에서만 이루어지며 최대 16개·32MB까지 보관합니다. 한도를 넘으면 오래된 이미지부터 제외하고,
한 장이 한도를 넘는 이미지는 수집하지 않습니다. 같은 이미지의 연속 복사는 중복 추가하지 않습니다.
이 한도는 보관하는 이미지 데이터 기준이며, PDF 저장 중의 전체 프로세스 메모리 상한을 의미하지 않습니다.
캡처 키를 전역 감시하거나 Windows 클립보드 기록을 조회하는 상주 프로그램은 설치하지 않습니다.

| 형식 | 필요한 프로그램 |
|---|---|
| PDF, JPG, JPEG, PNG, WEBP, BMP, TIFF | 없음 |
| TXT, CSV, MD | 없음. UTF-8/UTF-16/CP949 지원 |
| DOC, DOCX, RTF | Microsoft Word |
| XLS, XLSX, XLSM | Microsoft Excel |
| PPT, PPTX, PPTM | Microsoft PowerPoint |
| HWP, HWPX | 한컴 한글. 보안 확인창이 나타날 수 있음 |

Windows에서 열 수 있는 모든 파일을 지원하는 것은 아닙니다. 형식별 실제 검증 현황은 `docs/VALIDATION.md`를 확인하세요.
요약은 원문 문장 빈도에 기반한 발췌이며 생성형 AI 요약이 아닙니다. 스캔 이미지는 Windows 내장 OCR을 자동 사용합니다.
Windows 한국어 OCR 언어팩이 필요하며, 인식 결과는 원문과 비교해 주세요. 본문 수정과 생성형 AI 연결은 현재 포함하지 않습니다. 무손실 최적화는 용량 감소를 보장하지 않습니다.

### 추가 개발 중인 암호·보조 도구

사이드바 **암호·보조 도구**에서 PDF 선택 → 도구 선택 → 새 PDF 저장 순서로 사용합니다.

- AES-256 암호 설정/해제: 현재 암호, 새 열기 암호, 별도의 소유자 암호와 인쇄/복사 권한.
- 페이지 역순, 책 스캔 좌우 분리, 빈 페이지 제거, 여백 자르기.
- 메타데이터/XMP 제거, 텍스트 주민번호·전화·이메일·Luhn 유효 카드·SSN 삭제.
- `1-3, 5, 8-end` 페이지 범위 지원.
- **범위별 분할 / 페이지 수로 분할 / 목차별 분할**: 분할한 PDF들을 ZIP 한 개로 저장합니다. 목차 이전의 앞부분과 마지막 짧은 묶음도 보존합니다.
- Office/한글 변환 실패 시 설치된 LibreOffice를 독립 프로필로 실행하여 재시도.
- OpenCV 기울기·고대비 흑백 보정과 300DPI 이미지 사본.
- 45도 문구 워터마크와 투명 PNG 워터마크, 불투명도 조절.
- Windows 로컬 OCR의 투명 텍스트 레이어, 스캔 개인정보 이미지/텍스트 삭제.
- 뷰어 첫 페이지 자동 진단과 관련 도구 바로 실행. 전체 30ms 목표는 현재 미달입니다.
- **두 문서 비교**: 같은 페이지 번호끼리 시각 차이를 빨강(삭제)·초록(추가)·보라(같은 위치 변경)로 표시합니다. 좌우 슬라이더와 겹쳐 보기를 지원합니다. PDF 처리 후 **원본과 비교**에서도 열 수 있습니다.
- **발표자 화면**: 슬라이드쇼에서 현재·다음 페이지, 스티커 메모 대본, 경과 시간과 진도 경고를 봅니다. B/W로 화면을 검정/흰색으로 가리고 같은 키로 복원합니다. 보조 모니터가 있으면 발표자·청중 화면을 분리하며, 실제 듀얼 4K 장비 검증은 진행 전입니다.
- **발표 중 이동·공개**: G 키로 미리보기 그리드를 열어 원하는 페이지를 선택합니다. Space는 여러 텍스트 블록을 위에서부터 공개하고, 모두 공개하면 다음 페이지로 넘어갑니다. 스캔/한 블록 문서는 바로 다음 페이지로 이동합니다. 방향키와 클릭으로도 페이지를 넘길 수 있습니다.
- **발표 중 강조**: S로 스포트라이트, Ctrl+L로 레이저 포인터를 켜고 끕니다. 레이저 잔상은 0.5초 뒤 사라집니다. 청중 화면 또는 발표자 화면의 현재 페이지 미리보기에서 마우스를 움직여 조작합니다.
- **목표 용량 압축**: 암호·보조 도구에서 10MB·25MB 또는 직접 입력한 용량으로 압축합니다. 텍스트와 벡터를 유지하며 이미지 해상도·품질을 낮출 수 있습니다. 실제 출력 크기가 목표를 넘으면 저장하지 않고 최소 측정 용량을 안내합니다. 원본은 유지됩니다.
- **손상 PDF 복구**: 읽을 수 있는 페이지를 기준으로 교차 참조 구조를 재작성하고 텍스트·페이지 렌더링을 검증해 새 사본으로 저장합니다. 이미 유실된 본문이나 페이지를 복원하지는 못하므로 결과를 확인해 주세요. 암호 문서는 현재 암호가 필요합니다.
- **Markdown 내보내기**: 제목·본문·표를 페이지 출처와 함께 UTF-8 `.md` 파일로 추출합니다. 텍스트 없는 스캔은 먼저 OCR 처리해 주세요. 이미지와 복잡한 다단/병합 셀 구조는 원문 확인이 필요합니다.
- **SVG 벡터 내보내기**: 페이지별 SVG를 ZIP으로 저장합니다. 글자는 윤곽선으로 바꾸고 이미지는 SVG 내부에 포함하므로 별도 글꼴·이미지 파일 없이 표시할 수 있습니다. 외부 편집기에서 결과를 확인해 주세요.
- **페이지 세로 연결·A4 나누기**: 여러 페이지를 같은 너비로 연결하거나 긴 페이지의 빈 가로 구간을 찾아 A4로 나눕니다. 안전한 분할점이 없는 큰 구간은 축소해 보존합니다. 연결 시 원래 페이지 내부 여백은 유지되며 지원 높이는 14,400포인트까지입니다.
- **연속 식별번호·목차**: 접두어·시작 번호·자리 수를 지정해 번호를 붙입니다. 병합한 문서는 원본별 책갈피를 기준으로 클릭 가능한 목차 표지를 만들 수 있습니다(최대 40항목). 하단의 단순한 기존 페이지 번호는 텍스트 redaction으로 삭제하지만, 복잡한 머리말·이미지 속 숫자까지 제거하는 기능은 아닙니다.
- **입력 가능한 양식 만들기**: 빈 박스·밑줄·체크 칸을 PDF 양식 필드로 만듭니다. 뷰어의 **양식 입력**에서 현재 페이지의 텍스트와 체크 값을 입력해 새 PDF로 저장할 수 있습니다. 스캔 이미지는 제외하며 감지된 칸이 올바른지 확인해 주세요. 선택 목록·라디오 필드 편집은 아직 지원하지 않습니다.
- **4쪽 모아찍기·소책자**: A4 가로 인쇄용 PDF를 새로 만듭니다. 소책자는 접었을 때 읽는 순서로 페이지를 배치하고 부족한 쪽을 비웁니다. 소책자 출력 시 양면·짧은 쪽 넘김·실제 크기를 선택하고 프린터에 맞게 먼저 시험 인쇄해 주세요.
- 뷰어 하단 **페이지 이미지 복사**: 현재 페이지를 300DPI Windows 비트맵으로 복사합니다.
- **표 드래그 복사**를 켜고 표 전체를 드래그하면 HTML 표와 탭 구분 텍스트를 함께 복사합니다. 수식처럼 보이는 셀은 실행되지 않도록 텍스트 처리합니다. 스캔은 먼저 검색 가능한 PDF로 변환해 주세요.

원본은 보존하며 기존 출력 파일도 덮어쓰지 않습니다. 암호 설정 외 작업은 암호 없는 사본을 생성합니다.
일반 개인정보 도구는 기존 텍스트를 처리합니다. **스캔 개인정보 지우기**는 OCR로 인식한 영역의 이미지와 텍스트를 지우며, 인식 누락 가능성이 있어 제출 전에 결과를 확인해야 합니다.
LibreOffice 실제 변환은 현재 PC에 미설치되어 미검증이고 HWP/HWPX 전체 호환을 보장하지 않습니다.
이 변경들은 개발 소스에 반영한 상태이며 이전 설치파일에는 포함되지 않습니다.

공통 SDK 적용 범위는 [SDK 마이그레이션 현황](docs/SDK_MIGRATION.md),
전체 명세의 구현/미구현 구분은 [확장 구현 추적](docs/EXTENSION_STATUS.md)을 참고하세요.
서명·양식·책갈피 등 특수 문서는 결과를 확인한 뒤 사용하세요.

## 개발 실행 / 테스트 / 빌드

Python 3.11 이상과 Windows 10/11 x64에서 실행합니다. 우클릭 연결 프로그램에는 Windows의 .NET Framework 4.x를 사용합니다.
네이티브 모듈 빌드에는 Visual Studio 또는 Build Tools의 C++ 데스크톱 개발 도구와 Windows SDK가 필요합니다.

```powershell
python -m venv .venv_d
.\.venv_d\Scripts\python.exe -m pip install -r requirements.txt
.\.venv_d\Scripts\python.exe main.py
.\.venv_d\Scripts\python.exe main.py --quick merge "문서.pdf" "이미지.png"
.\.venv_d\Scripts\python.exe -m unittest discover -s tests -v
.\build_release.ps1
.\build_portable.ps1
```

빠른 명령: `--quick convert`, `--quick merge`, `--quick summary`. `--folder`로 저장 위치를 지정할 수 있습니다.
`--manifest`는 UTF-8 파일 목록을 받습니다. 탐색기 연결 프로그램은 COM IDropTarget으로 전체 선택을 한 번에 전달합니다.
API 키 설정이나 상주 서비스는 없습니다. 글꼴은 Pretendard를 포함합니다.

## 뷰어 상세 안내

PDF 더블클릭 또는 **PDF 열어보기**로 실행합니다. 왼쪽 작은 페이지를 클릭하면 이동합니다.
페이지 번호 직접 입력, ▲/▼ 버튼, 이전/다음 버튼을 사용할 수 있습니다.
**너비 맞춤**은 보기 영역의 가로 폭을 기준으로 비율을 유지합니다. 가로 문서는 아래쪽에 여백이 남을 수 있습니다.

### 중간 페이지 삭제 및 최종 저장

1. 삭제할 페이지의 미리보기에서 **X**를 누릅니다.
2. 확인창에서 삭제를 선택합니다.
3. 남은 페이지를 확인합니다. 원본 파일은 아직 변경되지 않습니다.
4. **저장 / Ctrl+S**를 눌러 새 PDF로 저장합니다.

여러 페이지는 **페이지 삭제**에서 범위로 지정할 수 있습니다. 모든 페이지 삭제는 허용하지 않습니다.
미저장 상태에서 닫으면 저장/버리기/취소를 선택합니다. PDF 본문 글자·이미지 자체 편집은 포함하지 않습니다.

## 라이선스 설정과 개인정보

설정·라이선스 화면은 Windows 표시 언어에 따라 한국어·영어·일본어를 선택합니다. 다른 언어는 한국어로 표시합니다. Qt 기본 대화상자도 해당 언어를 사용하며, 나머지 작업 화면의 다국어 전환은 진행 중입니다.

무료 이용도 **어잉PDF 상품 26818**에서 발급된 키가 필요합니다. 다른 상품의 라이선스는 사용할 수 없습니다.
설치 과정 또는 메인 앱의 **설정 · 라이선스 · 업데이트 → 라이선스**, 뷰어의 **라이선스**에서 관리합니다.

| 버튼 | 동작 |
|---|---|
| 활성화 / 재활성화 | 키를 현재 PC에서 활성화 |
| 상태 확인 | 서버에서 유효성과 활성 상태 확인 |
| 비활성화 | 현재 PC의 활성화를 해제. 같은 키로 재활성화 가능 |
| 라이선스 발급 페이지 | app.nal.la의 어잉PDF 상품 페이지 열기 |

키를 바꾸려면 기존 키를 먼저 비활성화하세요. 다른 PC로 옮길 때도 먼저 비활성화합니다.
프로그램 제거와 라이선스 비활성화는 별개입니다.

최초 활성화 성공 상태를 Windows DPAPI로 보호하여 저장하고, 이후에는 앱 재실행·PC 재부팅 후에도 오프라인 사용을 지원합니다. 상태 확인·비활성화·재활성화와 업데이트는 인터넷 연결이 필요합니다.
연결 실패로 새 권한을 부여하지 않으며 만료·중지·기기 수 초과 등을 한국어로 안내합니다.
무인 설치는 라이선스 창을 생략하고 첫 실행 때 활성화를 요구합니다.

키는 Windows DPAPI로 암호화하여 현재 Windows 사용자 범위에 저장합니다.
인증할 때 키·상품 ID·임의로 생성한 PC 식별자를 HTTPS POST로 서버에 전송합니다.
문서 내용, PC 이름, 하드웨어 일련번호는 보내지 않습니다. 키를 소스·배포 ZIP·명령줄·로그에 넣지 않습니다.
자세한 동작은 [라이선스 문서](docs/LICENSING.md)를 참고하세요.

## 실행 시 자동 업데이트

메인 앱과 PDF 뷰어 실행 후 EDD의 최신 버전을 백그라운드로 확인합니다.
새 버전이 있으면 설치 파일을 내려받고, 작업을 방해하지 않는 시점에 자동 설치 후 재실행합니다.

- 저장하지 않은 편집, 실행 중인 작업, 전체화면 슬라이드쇼, 열린 확인창이 있으면 적용을 기다립니다.
- 문서와 라이선스 저장 위치는 유지됩니다.
- 버전을 숫자로 비교하므로 `2.10.0`을 `2.9.0`보다 최신으로 판단합니다.
- 다운로드 실패 시 기존 앱을 계속 사용하고 다음 실행 때 재시도합니다.
- **설정 · 라이선스 · 업데이트 → 업데이트 → 지금 확인**에서 수동 확인을 시작하고 진행 상태를 볼 수 있습니다. 준비된 업데이트는 설정 창을 닫고 편집·작업을 마치면 적용합니다.
- 우클릭 전용 작업은 처리 후 종료하며 자동 설치를 시작하지 않습니다.

### EDD 운영자가 다음 버전을 배포하는 절차

1. 저장소의 `VERSION`을 올리고 `CHANGELOG.md`를 작성합니다.
2. 테스트 후 포터블과 설치 EXE를 빌드합니다.
3. app.nal.la의 **어잉PDF 상품 26818**에 새 설치 EXE를 등록합니다.
4. Software Licensing 버전 번호를 같은 새 번호로 설정합니다.
5. `get_version` 응답에 `new_version`과 활성 키가 사용할 `download_link`가 있는지 확인합니다.
6. 이전 버전에서 다운로드·설치·재시작을 검증한 뒤 배포합니다.

자동 설치 파일은 Windows 설치 EXE여야 합니다. 포터블 ZIP을 지정하면 설치 파일 검증에 실패합니다.
현재 다운로드 허용 호스트는 `https://app.nal.la/`이며 다른 호스트로의 리디렉션은 허용하지 않습니다.
CDN 등을 사용할 경우 신뢰할 호스트 정책을 코드와 함께 변경해야 합니다.
서버는 새 버전 응답에 설치파일의 `sha256`(64자리 16진수)을 반드시 제공해야 합니다. 정보가 없거나 실제 파일과 다르면 자동 설치하지 않습니다. 다운로드 완료와 설치 실행 직전에 SHA-256을 검사합니다.
연동 확인 당시 EDD 최신 버전 번호가 비어 있었습니다. 운영자가 버전과 설치 파일을 등록해야 실제 업데이트가 제공됩니다.

연동 기준: [EDD Software Licensing API](https://easydigitaldownloads.com/docs/software-licensing-api/).

## 자주 묻는 문제

**우클릭 메뉴가 안 보여요.** Windows 11의 ‘더 많은 옵션 표시’를 확인하세요. 포터블을 옮겼다면 메뉴 등록을 다시 실행합니다.

**PDF 아이콘이 바로 바뀌지 않아요.** 기본 PDF 앱이 어잉PDF인지 확인하고 탐색기를 새로 고침하세요. Windows 아이콘 캐시 반영에 시간이 걸릴 수 있습니다.

**전체화면을 닫고 싶어요.** 오른쪽 위 ‘전체화면 종료’, Esc 또는 F5를 사용합니다. 일반 뷰어는 ‘닫기’로 종료합니다.

**삭제했는데 원본은 그대로예요.** 원본 보존을 위한 동작입니다. 마지막에 저장하면 새 PDF에 삭제 결과를 반영합니다.

**한글/Office 변환이 실패해요.** 해당 프로그램 설치와 원본 문서의 정상 열림 여부를 확인하세요. 한글에서 보안 확인창이 나타날 수 있습니다.

**라이선스 확인이 실패해요.** 인터넷 연결, app.nal.la 접속 상태, 어잉PDF 상품용 키인지 확인하세요.

**자동 업데이트가 안 떠요.** 현재 버전이 최신이거나 EDD 버전 번호가 아직 등록되지 않은 경우입니다.

## 테스트 종류와 범위

```powershell
.\.venv_d\Scripts\python.exe -m unittest discover -s tests -v
.\.venv_d\Scripts\python.exe tests\ui_regressions.py
.\.venv_d\Scripts\python.exe tests\viewer_smoke.py
.\.venv_d\Scripts\python.exe tests\ui_smoke.py
```

- 엔진: 원본 보존, 페이지 처리, 출력 이름 충돌, 취소, 혼합 병합, 발췌 요약.
- 라이선스: 암호화 저장, 비활성화/재활성화, 키 교체 제한, 연결 실패와 폐기된 권한.
- 업데이트: 버전 비교, 누락/이전 버전 처리, 다운로드 출처 제한.
- UI: 첫 페이지 너비 맞춤, 창 크기 변경, 화살표, 한국어 버튼, 작은 창의 파일 선택 버튼.
- 뷰어: 미리보기 선택, 삭제 확인/취소, 임시 삭제와 최종 저장, 전체화면 조작 및 종료.

UI 단독 테스트에서는 라이선스 응답을 격리하며 실제 서버 검증과 구분합니다.
Office/한글/OCR과 설치형은 환경 의존 테스트입니다. [검증 기록](docs/VALIDATION.md)에 결과를 기록합니다.
테스트 통과가 모든 PDF에 대한 완벽한 호환성을 뜻하지는 않습니다.

## 설치형 빌드 및 배포 파일

```powershell
.\build_release.ps1
.\build_installer.ps1 -Compiler 'C:\Inno Setup\ISCC.exe'
```

`build_release.ps1`은 테스트, 네이티브 모듈, 아이콘과 PyInstaller 빌드를 수행합니다.
이전 배포를 백업하며 배포 폴더의 앱이 실행 중이면 교체를 중단합니다.
설치 제작에는 Inno Setup 6.x를 사용합니다. 자세한 절차는 [설치형 문서](docs/INSTALLER.md)를 참고하세요.

| 산출물 | 용도 |
|---|---|
| `EoingPDF-2.2.0-Setup-x64.exe` | 설치형 |
| `EoingPDF-{VERSION}-portable.zip` | 현재 VERSION을 파일명에 포함한 포터블 |
| `EoingPDF-{VERSION}-portable.exe` | 파일 하나로 실행하는 포터블 (이름 변경 가능) |
| `EoingPDF-{VERSION}-source.zip` | 명시적 목록으로 묶은 소스 |
| `SHA256SUMS.txt` | 배포 파일 체크섬 |
| `install-silent.cmd` | 같은 폴더의 설치 EXE를 `/S`로 무인 실행하는 배포 스크립트 |

소스 ZIP에 개인 문서, 환경 비밀값, 라이선스, 로그, 백업, 임시 파일을 넣지 않습니다.
단일 EXE는 실행할 때 필요한 구성 요소를 임시 폴더에 풉니다. 우클릭 메뉴를 직접 등록하면
작은 셸 도우미와 아이콘을 사용자 데이터 폴더에 보관하며, 등록을 해제하면 해당 파일을 정리합니다.
파일을 이동하거나 이름을 바꾼 뒤에는 새 위치에서 메뉴를 다시 등록하세요.
단일 EXE의 자동 교체·복원은 아직 구현 중이며 새 포터블 파일을 받아 수동으로 교체해야 합니다.
앱 아이콘 원본은 `assets/app_icon.png`, PDF 문서 아이콘 원본은 `assets/pdf_icon.png`입니다.
빌드 때 비율과 투명도를 유지한 16~256px ICO를 생성합니다.

## 개발 문서

### 폴더 안의 문서 내용 검색

왼쪽 **문서 내용 검색**에서 PDF가 있는 폴더를 선택하면 하위 폴더까지 읽습니다. 찾고 싶은 내용을 문장으로 입력하고 Enter를 누르세요. 결과는 내용의 유사도 순서이며, 결과를 더블클릭하거나 **선택한 페이지 열기**를 누르면 뷰어가 해당 페이지와 구간을 표시합니다. 답변을 생성하는 챗봇이 아니라 원문 위치를 찾는 기능입니다.

- **스캔 PDF 글자 인식 포함**을 켜면 이미지 속 글자도 Windows OCR로 읽습니다. 텍스트와 이미지가 섞인 페이지도 처리하며 Windows OCR 언어 팩이 필요합니다. 페이지 수가 많으면 시간이 더 걸립니다.
- 문서가 바뀌면 **폴더 다시 읽기**를 누르세요. 내용이 바뀌거나 삭제된 파일의 이전 결과는 표시하지 않습니다.
- **작업 취소**나 창 닫기는 진행 중인 작업을 종료하고, 이미 완성된 기존 색인은 유지합니다.
- **검색 자료 삭제**는 선택한 폴더의 검색용 텍스트·색인을 삭제합니다. 원본 PDF는 삭제하지 않습니다.
- 색인은 `%LOCALAPPDATA%/EoingPDF/search`에 저장됩니다. 검색용 텍스트가 포함되며 별도 암호화 저장은 아직 지원하지 않습니다. 암호가 필요한 PDF는 현재 색인에서 제외됩니다.
- 한 폴더에서 최대 2,000개 파일, 파일당 최대 10,000쪽, 전체 100,000개 텍스트 구간을 처리합니다. 이미지 인식 실패 등 제외된 문서의 사유는 처리 상태의 설명에서 확인합니다.

검색 모델은 프로그램에 포함되어 오프라인으로 실행됩니다. 최초 라이선스 인증과 업데이트 외에 문서나 검색어를 서버에 보내지 않습니다. 모델 정확도와 성능은 [검색 평가 기록](docs/SEARCH_MODEL_EVALUATION.md)에서 확인할 수 있습니다. 현재 개발 빌드에서 검증 중이며 모든 문서의 검색 정확도를 보장하지 않습니다.

개발 시 모델을 다시 준비하려면 평가 의존성을 설치한 뒤 `scripts/prepare_search_model.py --external`, `scripts/package_search_model.py`를 실행합니다. 릴리스 빌드는 포함된 모델의 고정 해시와 출처 파일을 확인하며, 앱 실행 중 모델을 다운로드하지 않습니다.

### 자동 업데이트 복구

자동 업데이트는 설치 직전에 관리 대상 프로그램 파일의 전체 스냅샷과 SHA-256을 저장합니다. 업데이트 뒤 별도 프로세스가 폰트와 PDF 뷰어 실행을 검사하고, 실패하면 스냅샷 복원을 시도합니다. 설정 화면 또는 `EoingPDF.exe --rollback-update`로 검증된 최근 백업을 복원할 수도 있습니다. 사용자 문서를 백업·복원 대상으로 삼지 않습니다. 실제 교차 버전 설치, 전원 중단, 제거 정보와 셸 등록 복구, 코드 서명은 추가 배포 검증이 필요합니다.

단일 EXE도 이름과 위치를 유지하는 자동 교체·복원을 지원합니다. 서버에 포터블 전용 다운로드와 해시가 등록되어야 하며, 실행 파일 하나만 백업합니다. [포터블 업데이트 규격](docs/PORTABLE_UPDATES.md)을 참고하세요.

일본어 목차·연번·워터마크·텍스트 PDF는 필요한 경우 내장 CJK 글꼴을 사용합니다. 해당 글꼴을 PDF에 포함하므로 다른 PC의 글꼴 설치 여부에 의존하지 않습니다.

암호가 걸린 PDF도 뷰어에서 암호를 입력해 바로 열 수 있습니다. 페이지 삭제 후 새 사본으로 저장하면 기존 암호가 유지됩니다. 암호를 입력하다 취소하면 열려 있던 문서는 그대로 유지합니다.

### 도장·서명 찍기

보조 도구에서 **도장·서명 찍기**를 선택하고 PNG/JPEG를 불러오세요. 흰 배경과 외곽의 빈 여백을 자동으로 제거합니다. 찍을 페이지(`1, 3-5, 8-end`)와 화면의 왼쪽·위쪽에서 떨어진 거리, 너비를 mm로 지정합니다. 페이지 밖으로 나가는 배치는 저장하지 않습니다.

기본값인 **전체 PDF를 300DPI 이미지로 합치기**를 사용하면 문서와 도장을 이미지로 합칩니다. 전체 문서의 텍스트 검색·양식·링크 기능은 사라집니다. 체크를 해제하면 기존 텍스트와 도형을 유지하고 도장 이미지만 추가합니다. 저장 후 **원본과 비교**로 위치를 확인하세요. 이미지 날인이며 인증서를 사용하는 전자서명은 아닙니다. 도장 보관함에서 이름을 붙여 추가하고 미리보기·다시 사용·삭제할 수 있습니다. 이름과 이미지 모두 Windows DPAPI로 암호화하며 평문 임시 이미지를 만들지 않습니다. 저장한 Windows 계정에 묶이므로 다른 계정이나 PC로 옮기는 용도의 백업은 아닙니다. 같은 계정의 다른 프로그램에 대한 별도 잠금도 아닙니다. 보관함 파일은 `%LOCALAPPDATA%/EoingPDF/seals`에 저장합니다. 원본 이미지 파일은 사용자가 관리하며 자동으로 삭제하지 않습니다.

### 작은 창에 파일 모으기

왼쪽 **작은 창에 파일 모으기**를 누르면 다른 창 위에 작은 드롭존이 나타납니다.
여러 폴더에서 파일을 끌어오고 목록 순서를 바꾼 뒤 **하나의 PDF로 합치기**를 누르세요.
기본 저장 위치는 목록 첫 파일의 폴더이며 다른 저장 폴더를 선택할 수도 있습니다.
원본은 보존하고 같은 이름의 결과는 번호를 붙여 저장합니다. 지원 문서를 최대 1,000개 모을 수 있습니다.
화면 가장자리에 가까이 옮기면 붙고, 창을 닫으면 목록만 비웁니다. 파일을 삭제하지 않습니다.
작업 중 닫기는 취소가 끝난 뒤 종료합니다. 단독 실행은 `EoingPDF.exe --dock`입니다.
